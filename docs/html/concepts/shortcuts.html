Keyboard and mouse#

Every shortcut and mouse action the plugin adds, in one place. ComfyUI's own shortcuts (queue, copy and paste, undo, ...) are unchanged. Keys on the canvas act only when no text field has the focus.

Network editor (canvas)#

InputAction
Tab (pointer over the canvas)Open the PCG node menu at the pointer, like Houdini's Tab menu. It lists only PCG nodes.
Type in the menuSearch by subsequence: pe finds PolyExtrude, grcr Group Create.
↑ / ↓, Ctrl+P / Ctrl+NMove in the list.
EnterCreate the node at the pointer.
Esc, TabClose the menu.
Y + left-dragCut every wire the drawn line crosses. Esc cancels.
Alt + left-drag on two or more selected nodesArrange them in a column (drag vertically) or a row (drag horizontally). Esc cancels.
Shake a node while draggingDisconnect all its wires.
Press and drag the last third of a wireMove its input end to another input; dropped on empty canvas it disconnects.
Press and drag the first third of a wirePull a new wire from the same input to choose another output.
Shift while dragging a nodeDo not snap to wires and neighbours.
Drop a wire on a panel cellConnect it to that parameter.
Click the blue square above a nodeShow the node in the floating 3D panel (display flag). Again: clear it.
Click the grey square, or right-click / Ctrl+click the blue oneUse the node as the template (grey wireframe).
Click a COP node's thumbnailNext layer (when there are several), otherwise the next display mode.
Shift+click a COP thumbnailNext display mode: auto, clamp, signed, normalize.
Hover a COP thumbnailShow the pixel value under the pointer.

Wire style, snapping and the other canvas behaviour are described on Wires.

Parameter panel#

InputAction
Type a number, EnterSet the value (replaces any expression, reference or keys).
Type a formula, EnterStore it as an expression (the field turns cyan).
EscAbandon the edit.
↑ / ↓ in a number fieldStep the value; Shift ×10, Ctrl ×0.1. In a keyed field this sets a key; fields driven by an expression or reference do not step.
Drag left / right on a number fieldScrub the value; Shift faster, Ctrl slower.
Alt+click a fieldSet a keyframe at the current frame. Alt+click the label: key the whole row.
Alt+Shift+click a fieldDelete the keyframe at the current frame.
Hold the middle mouse button on an expression or referenceShow its current value.
Click a parameter's labelToggle that row between expression and value.
Right-click a row or cellCopy Parameter, Paste Relative References, keyframes, Disconnect, Revert to Defaults ...
▾ next to a group or attribute fieldPick a name that exists on the upstream geometry.
Tab in a code or multi-line fieldInsert 4 spaces (instead of moving the focus).

Ramps

InputAction
Click an empty spotAdd a key there and keep dragging it.
Drag a keyMove it (left / right = position, up / down = value on a float ramp).
Double-click a colour keyPick its colour.
Right-click a key, or Delete / BackspaceRemove the selected key (one always remains).
← / →Select the previous / next key.

Edit Parameter Interface dialog: Esc closes it; Delete removes the selected parameter (when no field is being edited).

3D viewport and floating panel#

InputAction
Left dragTumble.
Middle dragTrack (pan).
Right drag, mouse wheelDolly.
Double-click, F / G / H / HomeFrame all.
1 / 2 / 3 / 4Perspective / top / front / right view (also leave the UV view).
5UV view on / off. In the UV view: left or middle drag pans, right drag or the wheel zooms (about the pointer), F frames the layout.
Alt or Space + left dragTumble, even while a handle or the curve tool is active.

Keys act while the pointer is over the view, also when a toolbar menu of the panel still has focus; only a text box being typed in keeps its keys.

Handles (select a node that has one, see Handles):

InputAction
T / R / ETranslate / rotate / scale handle.
Drag an arrow / square / centre circleMove along an axis / in a plane / in the screen plane.
Drag a ringRotate.
Drag a scale box / the centre boxScale along an axis / uniformly.
Ctrl while draggingSnap: a tenth of the grid unit, 15 degrees, steps of 0.1.

Curve tool (select a Curve node):

InputAction
Click empty spaceAdd a point at the end (on the geometry under the pointer, or on the construction plane).
Drag a pointMove it. Shift: snap to the surface; Ctrl: snap to a tenth of the grid unit.
Ctrl+click a segmentInsert a point.
Delete / Backspace over a pointRemove it.
Click the first pointClose the curve.

Playbar#

Shown when the graph has a Frame (PCG) node.

InputAction
SpacePlay / pause.
← / →Previous / next frame.

These act only when no text field has the focus and no modifier key is held; the keyboard button on the playbar turns them off.

Geometry Spreadsheet#

The mouse wheel scrolls the table (not the canvas); the tabs switch between point, vertex, primitive and detail.
